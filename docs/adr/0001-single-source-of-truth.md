# ADR-0001. Отдельный репозиторий контрактов

Связанный глобальный ADR: `workout-docs/adr/0001-multi-repo-strategy.md`.

## Статус
Принято.

## Контекст
Порядок разработки: Desktop (Python) → Android (Kotlin) → ESP32 (C/C++).
Прямой перенос кода не предполагается, риск расхождения поведения высок.

## Решение
Вынести формат конфигурации, команды, события, состояния, ошибки, каталог
уведомлений и конформанс-векторы в отдельный репозиторий без исполняемой логики.
Подключение: git submodule для C/C++, пакет или submodule для Python и Kotlin.

## Следствия
- Изменение поведения начинается с изменения контрактов и векторов.
- Расхождение реализаций обнаруживается тестами, а не в тренировке.
- Появляется накладной расход на синхронизацию версий.

## Альтернативы
Дублирование моделей в каждом репозитории: отклонено из-за неизбежного дрейфа.
Единое ядро на Rust/C++ сейчас: отклонено как преждевременное усложнение MVP.
