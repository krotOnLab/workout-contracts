# ADR-0004. Разделение workout и runtime

## Статус
Принято.

## Решение
`workout` — переносимое определение тренировки, единственная часть, которая
экспортируется на Android и ESP32. `runtime` — настройки хоста: устройства
ввода, аудио, пороги уверенности, политика пропуска по умолчанию.

Нормализация удаляет `runtime`. На устройстве политика приходит из его
собственных настроек профиля.

Вынос `runtime` в отдельный `profile.yaml` не выполняется.

`runtime` остаётся необязательным блоком в том же пользовательском документе
тренировки. Нормализация в канонический JSON удаляет `runtime`.

Это решение принято как компромисс между чистотой разделения ответственностей
и удобством редактирования одного файла тренировки пользователем.

## Обоснование
Пороги уверенности распознавания и наличие клавиатуры не имеют смысла на
ESP32 и не должны влиять на семантику этапов. Смешивание приведёт к тому,
что один и тот же файл даёт разное поведение на разных платформах.
